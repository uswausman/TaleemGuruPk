## 📚 About TaleemGuru

**TaleemGuru** is an online education and exam-preparation platform designed to help Pakistani students learn, practice MCQs, prepare for examinations, and improve their academic performance.

### ✨ Key Features

* 📖 **MCQs & Question Banks** — Practice subject-wise questions.
* 📝 **Notes & Study Material** — Access academic learning resources.
* 🎯 **Online Tests** — Prepare with practice tests and assessments.
* 🏫 **Board Exam Preparation** — Resources for Classes 9–12.
* 🩺 **Medical Entry Tests** — MDCAT and NUMS preparation.
* ⚙️ **Admin Dashboard** — Manage academic content and platform settings.
* 📊 **Student Dashboard** — Access learning resources and track available results.
* 🛡️ **Website Command Center** — Monitor website health, SEO, errors, APIs, and database diagnostics.

## 💻 Run Locally

### Prerequisites

* Node.js
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/uswausman/TaleemGuruPk.git
   cd TaleemGuruPk
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure the environment variables required by the application in your local environment file. Use the project's existing environment-variable names and never commit secrets.

4. Start the development server:

   ```bash
   npm run dev
   ```

## 🔐 Security

* Keep API keys and database credentials private.
* Never commit `.env` files containing secrets.
* Use server-side authorization for protected administrative operations.
